# Student Management System in C

A console-based Student Management System developed using the C programming language.  
This project demonstrates core programming concepts, file handling, data management, and menu-driven application development for academic and interview preparation purposes.

---

# Project Overview

The Student Management System allows users to manage student records through a simple command-line interface.

The project is designed to strengthen understanding of:

- Structures in C
- Functions
- Arrays
- File Handling
- Menu-driven programming
- Data management logic

---

# Features

- Add Student Record
- Display Student Details
- Search Student by ID
- Update Student Information
- Delete Student Record
- Store Records Efficiently
- Menu-driven User Interface

---

# Technologies Used

- C Programming Language
- GCC Compiler
- VS Code
- Command Line Interface (CLI)
